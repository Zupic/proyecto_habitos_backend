El proyecto hábitos cuenta con su backend y frontend, en su backend permite la conexión a una base de datos donde se almacenan los hábitos que el usuario desea adquirir. 
Para ejecutar el proyecto, se abre el backend/clase1 en VisualStudio, en la terminal con el comando npm start se conecta a la base de datos. 
De igual forma se abre la carpeta frontend/habitos-semana2 en VisualStudio, en la terminal ingresamos npm run dev, luego en el buscador de Google Chrome se ingresa en la url localhost:3000, inspeccionar, Redux.
